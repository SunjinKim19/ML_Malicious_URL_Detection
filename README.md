# ML_Malicious_URL_Detection
Malicious_URL_Detection

Project Title: Deep Learning-based Malicious URL Detection
Objective: 악성 URL 탐지 문제에서 데이터 불균형을 극복하고, 원본 URL 텍스트 패턴을 스스로 학습하는 1D-CNN 기반 이진 분류 모델 구현.
Key Metric: F1-Score, ROC-AUC (불균형 데이터 평가를 위한 지표 선정)
Data Source: Kaggle Malicious URLs Dataset (Academic use)
